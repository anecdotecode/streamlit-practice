How to play hangman

目的

伏せられた英単語を、1文字ずつ当てて完成させる。

遊び方

  1. 画面に、単語の文字数分の下線(_)と絞首台の絵が表示される。単語は単語リストからランダムに選ばれる。
  2. A〜Z のボタンから、単語に含まれると思う文字を選ぶ。
  3. 含まれていれば、その文字が入る位置すべてに同時に表示される。
  4. 含まれていなければミスになり、絵が1段階進む。
  5. すべての文字を当てれば勝ち(CLEAR)。

選んだ文字

  • 一度選んだ文字のボタンは ❌ 表示になり、押せなくなる。

ミスとゲームオーバー

  • ミスは8回まで。8回目のミスで GAME OVER になる。

結果の表示

  • CLEAR または GAME OVER の画面に、答えの単語と日本語の意味が表示される。
  • CONTINUE? ボタンを押すと、新しい単語で最初からやり直せる。ミスの回数と選択済みの文字はリセットされる。
  • 単語はランダムに選ばれ、出題済みの単語を除く処理はない。同じ単語が再び出ることがある。
