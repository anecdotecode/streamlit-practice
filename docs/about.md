# Two games are here

Streamlit で作った2つのゲーム、hangman と high and low の遊び方をまとめたサイト。

[アプリを開く](https://app-practice-8da4fnwuy2hjuejq3dbnwm.streamlit.app/){ .md-button .md-button--primary }

## 使っているもの

- アプリ: Python / Streamlit
- このサイト: MkDocs / Material for MkDocs

## 素材

- hangman の単語リスト: 作者が作成
- カード画像: PixAI の Tsubaki.3 で生成し、数字は作者が書き加えた
- スートのアイコン: Claude が作成
