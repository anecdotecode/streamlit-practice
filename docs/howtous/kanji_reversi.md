# How to play kanji reversi

!!! abstract "目的"

    リバーシで勝つ。または、盤面に隠れた漢字を当てる。どちらか先に達成すれば勝ち。

## 始める前に

1. 自分の色(黒=先手 / 白=後手)を選ぶ。
2. 敵の強さを選ぶ(激よわ / よわ / ふつー / つよ / げきつよ。初期値は ふつー)。
3. `対戦開始` を押す。漢字は、毎回リストからランダムに1文字選ばれる。

## 遊び方

1. 自分の番になると、置けるマスに黄色い点が出る。点のあるマスをクリックして石を置く。
2. 挟んだ相手の石は裏返り、自分の石になる。
3. 盤面の**自分の石があるマス**には、後ろに隠れた漢字の一部が見える。
4. 一部を手がかりに漢字を推理し、予想欄に入力して `予想する` を押す。

!!! tip "漢字の見え方"

    漢字は盤面全体(8×8)に広げた1枚の絵になっていて、各マスはその1/64を担当する。
    自分の石があるマスだけ、そのマスの領域(石の外の四隅を含む)が表示される。
    石を裏返されると、そのマスの漢字は見えなくなる。取り返せば、また見える。
    相手の石のマスと空きマスには、漢字は出ない。

## 漢字の予想

- 予想は自分の番のときだけできる。**予想しても手番は消費しない**。
- 入力は漢字1文字。空欄や2文字以上は予想として数えず、「漢字を1文字で入力してください」と表示される。
- 外れても何度でも続けられる。
- 当たればその場で勝ち。

## 勝敗

| 条件 | 結果 |
|---|---|
| 漢字を当てた | あなたの勝ち |
| 盤面が埋まる、または両者とも置けなくなったとき、石の数が多い | その石の色の勝ち |
| 石の数が同じ | 引き分け |

!!! info "パス"

    置ける場所がないときは自動でパスになり、相手の番に移る。「あなたはパスしました」「相手はパスしました」と表示される。

!!! note "終了後の表示"

    勝敗に関わらず、終了すると答えの漢字が表示される。

## 敵の動き

敵は一定時間を置いてから打つ。強さが上がるほど待ち時間が長い。敵が考えている間は盤面を押せないが、`最初から遊ぶ` は押せる。

!!! danger "リセット"

    `最初から遊ぶ` を押すと、対局は破棄されて設定画面に戻る。
